# agentic-screaming-java

Examples from the YouTube course "Screaming Java for Agents: Less Prompting, More Confidence", the successor to "Screaming Architecture with BCE".

[![Screaming Java for Agents: Less Prompting, More Confidence](https://img.youtube.com/vi/hVvNZq7MTdU/hqdefault.jpg)](https://www.youtube.com/playlist?list=PLYmJ34GQMFrI)

Watch the course: [YouTube playlist](https://www.youtube.com/playlist?list=PLYmJ34GQMFrI)

Each example is a small Java 25 system organized with Boundary-Control-Entity (BCE), so the package structure states what the system does. Coding agents write, review and test the code on camera; the BCE layout and the tests, not long prompts, keep the agents on track. One directory per example, tagged per episode.

Workshops, courses and consulting on Java, BCE and coding agents: [airhacks.io](https://airhacks.io)
